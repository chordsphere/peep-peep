The purpose of this project will be to build an application specifically for my environment i'm working in now (laptop, wsl, windows 11, etc) to record my screen in strategic moments with extra simplicity and predictability. One example is that if I want to record a quick tutorial for operating bale, I should be able to call up the screen recording with a simple custom cli command, it records my entire screen with a full suite of tools, then when I end, it pops up with custom post processing, editing, or a preset of commands. The point will be to reduce friction as much as possible because I'll be making a lot of screen recordings. Something else is that I don't want to use a third party service (as much as can be reasonably limited), so if we need to develop the tooling ourselves that's within scope.
